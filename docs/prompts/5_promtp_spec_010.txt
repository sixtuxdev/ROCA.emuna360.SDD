# Acceso según Administrador de Denominación

Sólo el Administrador de la Denominación puede acceder al módulo completo de configuración de Iglesias.

Para validar esto debes consultar el LocalStorage usando la Key:

`IsAdminDenominacion`

Si el valor es:

- `true`:
  - Puede acceder a `ConfigIglesias.razor`.

- `false`:
  - No debe acceder al módulo completo.
  - Debe ser dirigido a otro componente.

# Carga jerárquica Geography

La carga debe ser dependiente:

1. Selecciona País.
2. Se cargan Departamentos del País.
3. Selecciona Departamento.
4. Se cargan Ciudades del Departamento.
5. Selecciona Ciudad.
6. Se cargan Corregimientos de la Ciudad.

No cargues toda la geografía masivamente.

Cuando cambie un valor superior debes limpiar automáticamente los inferiores.

Ejemplo:

- Cambia País:
  - Limpiar Departamento.
  - Limpiar Ciudad.
  - Limpiar Corregimiento.

- Cambia Departamento:
  - Limpiar Ciudad.
  - Limpiar Corregimiento.

- Cambia Ciudad:
  - Limpiar Corregimiento.
